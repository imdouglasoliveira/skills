# Production Lessons and Anti-Patterns

This reference compiles critical architectural lessons, operational incidents, and anti-patterns encountered across remote MCP deployments.

---

## Lessons Summary

| Problem | Root Cause | Fix | Where It Bites |
|---|---|---|---|
| Scope map drift | Maintaining tool scopes in a separate hand-written dictionary caused permissions to fall out of sync with tools. | Derive the scope map automatically from tool definitions using `scopeMap()` and lock with a parity test. | Tools/call authorization checks |
| Premature request rejection | Edge gateway rejected incoming OAuth or PAT tokens before reaching function code because gateway expected Supabase Auth JWTs. | Configure `verify_jwt = false` in gateway config and perform authentication inside handler code. | Supabase Edge Functions |
| Path routing failure | Edge runtime stripped `/functions/v1/` prefix on some environments while preserving it on others. | Accept both prefixed and root pathnames in the HTTP router. | Edge Function URL routing |
| Resource URL rejection | OAuth clients failed authorization because the `resource` parameter differed by a trailing slash. | Strip trailing slashes and perform strict byte-for-byte audience matching in `/authorize` and `/token`. | OAuth 2.1 discovery and token exchange |
| Misleading 401 error | Database query failure returned HTTP 401 `invalid_client` instead of HTTP 500 `server_error`, causing clients to discard valid credentials. | Differentiate credential mismatches (401) from database exceptions (500). | Token endpoint error handling |
| Sensitive credentials in logs | Storing raw JSON arguments exposed user passwords, tokens, and documents in audit logs. | Filter arguments through `redactArgs()` to mask sensitive keys before insertion. | Request audit logging |
| Log storage exhaustion | High-volume tool calls caused the audit log table to consume gigabytes of storage without bounds. | Implement scheduled purge (`fn_mcp_purge`) via cron to expunge logs older than the retention window. | Long-term operational maintenance |
| Untracked ceiling changes | Operators could not identify who modified user domain ceilings when diagnosing unauthorized access. | Track every modification in `mcp_user_ceiling_history` recording who, when, from_level, and to_level. | Access administration audit |
| Silent result truncation | Truncating query results without notifying the AI model caused agents to assume incomplete lists represented total counts. | Return an explicit `notice` object with `cut_at` and pointer to the full-list pagination tool. | List queries and data retrieval |
| Unauthorized ceiling read | Management RPCs checked session presence but omitted role verification, allowing any authenticated user to view company ceilings. | Call `fn_mcp_is_admin()` inside all `rpc_mcp_admin_*` functions to enforce administrative role. | Admin procedure calls |
| PAT client OAuth confusion | Returning 401 with OAuth discovery challenge headers caused headless PAT clients to attempt interactive browser flows. | Tailor 401 response challenge headers and workarounds based on client user-agent. | CLI and headless integrations |
| Accidental static repo publish | Deno Deploy build misconfiguration published the repository root as static assets rather than executing backend code. | Deploy automated leak probes requesting private files to verify static serving is disabled. | Deno Deploy hosting |
| Cross-tenant data leakage | Cloudflare D1 does not offer native RLS, allowing queries that omit tenant filters to access records across tenants. | Route all database queries through an abstraction helper requiring explicit `tenant_id` and `user_id`. | Cloudflare Workers + D1 |
| Burst session invalidation | Concurrent tool calls from the same user generated multiple magic links simultaneously, invalidating each other. | Implement encrypted session token reuse with an in-memory or database mutex lock per user. | Parallel AI agent execution |
| Security bypass via service role | Querying business tables with the database service role bypassed Row Level Security policies entirely. | Execute business data queries strictly using the user's authenticated context JWT. | Supabase database access |
| Accidental destructive mutation | Autonomous AI agents executed permanent deletion commands when exploring tools without human intervention. | Server-enforced confirmation: first call returns a link and preview, execution only after the user confirms on a host-app page; see `confirmation.md`. | Sensitive tool handlers |
| Self-confirmation by the model | A literal `confirm` field, text instructions and `destructiveHint` were all bypassed: the model fills the field, skips the text, and the client's "always allow" ignores hints. | Move consent to a channel the model cannot write: single-use confirmation bound to user, connection, tool and argument hash, decided on a page that refuses delegated sessions. | Sensitive tool handlers |
| `aal2` read as presence proof | Users with an enrolled factor already browse at `aal2`, so an agent driving their browser could press Confirm. | Require a recent TOTP entry in the session claims, with a window per class. | Confirmation page and decision function |
| Confirmation stored personal data | The preview kept names, emails and amounts for months. | Null the preview when the confirmation ends, purge rows in days, mask items. | Confirmation table |
| Client schema validation rejects the pending result | `structuredContent` was validated against an `outputSchema` that did not allow the pending shape. | Publish `outputSchema` as `anyOf` of the tool output and the pending output. | `tools/list`, sensitive tools |
| False positive unit tests | Mocks masked schema column renames and SQL syntax bugs, allowing broken migrations into staging. | Supplement mocks with real SQL migration smoke tests verifying actual column and RLS existence. | Pre-deployment verification |
| Error detail erasure | External SDK helper `functions.invoke` cleared response `data` to null on non-2xx status codes, hiding error details. | Read the `error` object or use native `fetch` to capture structured JSON error payloads. | Client integration testing |
| Refresh token hijack | Compromised refresh tokens allowed attackers to maintain persistent access after user password changes. | Implement single-use refresh token rotation and revoke the entire token family upon token reuse. | OAuth session persistence |
| Strict rotation logged people out | A client running several sessions presented an already-rotated refresh and the family was revoked; people reconnected every hour | Short grace window for the previous refresh, or an owner-recorded decision to keep it valid until expiry; idle expiry as backstop | OAuth session persistence |
| Second factor only on the screen | The consent page asked for the code, but the function that recorded consent accepted a session without it | Check the assurance level inside the function too | Consent and admin RPCs |
| Write marked read-only skipped the client prompt | Clients prompt from annotations; writes without `destructiveHint` or `readOnlyHint: false` ran with no question | Audit annotations of every write; a parity test per class | `tools/list` |
| Public file links in records | Attachments saved as permanent public URLs opened for anyone holding the link | Private storage, path in the record, signed read link when shown | Uploads |
| In-band logging deprecation | Protocol specification 2026-07-28 deprecated MCP in-band logging notifications, breaking legacy handlers. | Direct operational logs to custom audit tables or OpenTelemetry instead of in-band MCP protocol channels. | Protocol conformance |
| Origin tools exposed generic search | A host `search` shown to anyone with read in any domain also showed up for people holding only the origin domain | Compute "any read" over host domains only | Aggregator ceiling |
| Refresh token lost on parallel calls | Single-use rotating refresh used by two concurrent tool calls, or consumed with no time left to store the new pair | Per-person lock, conditional write before use, minimum time margin to write | Aggregator token refresh |
| Static guards turned red by the dynamic path | The new path reordered the rate cap, the refusal row or the session open of the static path | Keep the static path identical; compare red sets with the base | Aggregator wiring |
| Connection concluded after downgrade | A connect exchange in flight finished after the person was disconnected or lowered | Re-check request, ceiling and tenant inside the conclude transaction | Aggregator connect |
| Secret hidden by truncation | Error text was cut to 300 characters before the secret scan | Scan the full text first, cut last | Aggregator error translation |
| Origin silently stopped marking a tool destructive | Classification followed the latest annotation only | Sticky per-tenant classification; admin reclassifies explicitly | Aggregator classification |
| Connection with no origin scope | The OAuth function was not redeployed after adding the domain | Redeploy it with the new scope and tell people to re-consent | Aggregator rollout |
| Empty list from a failed source | A lookup failed and returned `[]`; the assistant reported "there are none" | Return `could not read` with a reason, distinct from empty | Tool output |
| Partial update erased a valid value | An invalid field in a partial update was dropped during merge and the stored value was deleted | Validate the partial payload before merging; refuse with "nothing was written" | Write tools |
| Session failure answered with 401 | The client read 401 as an expired token and asked the user to reconnect | Return a tool error with `(ref N)` | `tools/call` session step |
| Every token rejected after deploy | The function named a new column before its migration ran | Select tolerant of both schemas; ship the migration first or fill by trigger | Deploy order |
| Count from a truncated search | The model reported a total after seeing a capped `search` result | Counts come from list tools; `search` always warns when it cut | Generic search |
| Ceiling ignored by side doors | REST upload routes checked the raw token scope, so lowering a ceiling did not reach them | One preflight and pipeline for every entry point (N-21) | REST doors, bots, queues |
| Guard green after identity mapper changed | A guard was tested with a hand-built identity; later every PAT was labeled as OAuth and the tests stayed green | Prove identity-dependent guards with real credentials through the real route | Guard tests |
| Re-consent loop on a tool refusal | A scope refusal inside `tools/call` returned HTTP 403, and the client restarted authorization | Return `isError: true` naming the scope; 403 only for whole-request refusals | `tools/call` scope check |
